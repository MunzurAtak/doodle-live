# Doodle Live

You get a word and 20 seconds to draw it. While you draw, an AI watches every stroke and
guesses out loud, like a game-show contestant.

Two models work together, entirely in your browser:

- **The eyes:** a stroke-sequence transformer trained from scratch in PyTorch on Google's
  Quick, Draw! dataset, exported to ONNX and run with onnxruntime-web.
- **The voice:** a small open-source LLM (Qwen2.5 via WebLLM, on your GPU) that only sees
  what the classifier reports and turns it into live commentary.

No server, no API keys.

> 🚧 Work in progress.

## Repo layout

```
ml/        Python: data download, preprocessing, model, training, evaluation, ONNX export
web/       Vite + React + TypeScript app (deployed to GitHub Pages)
shared/    Cross-language golden fixtures generated by ml/, consumed by web/ tests
reports/   Evaluation outputs used in this README
```

## Run locally

```bash
# ML (from ml/)
uv sync
uv run pytest

# Web (from web/)
npm ci
npm run dev
```
